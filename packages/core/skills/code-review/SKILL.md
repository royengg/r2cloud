---
name: code-review
description: 'Find actionable correctness, security and regression risks.'
---

Inspect the change and its callers, contracts and affected behavior. Prioritize demonstrable bugs, authorization failures, data loss, race conditions and missing failure handling over style preferences.
For each finding provide the concrete trigger, consequence and file location. State uncertainty where evidence is incomplete. Do not invent issues to fill a quota.
Review without modifying files unless the user asks for fixes. Summarize testing gaps and say when no actionable findings were found.
