# Design sources

References behind the visual system in [DESIGN.md](../DESIGN.md).

- [Google DESIGN.md specification](https://github.com/google-labs-code/design.md/blob/9bf8eae67128b6cc55ad9bf86665767deb4c11cd/docs/spec.md): structured tokens and ordered rationale in the root DESIGN.md.
- [Emil Kowalski — design engineering](https://github.com/emilkowalski/skills/blob/d23d7f88a2e21c9e4b1418c7abe420f5c1052ba7/skills/emil-design-eng/SKILL.md): purposeful motion, press feedback, restrained transitions and interaction detail.
- [Jakub Krehel — interface skills](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e/skills): accessibility, layout, writing, typography, color and UI polish. Applied the better-interface domain guidance and relevant font, surface and icon references.
- [Hugeicons React](https://hugeicons.com/docs/integrations/react/overview): shared HugeiconsIcon renderer with individually imported free Stroke Rounded icons.

Upstream skill text is not republished in this repository. The design system uses original project tokens, soft surfaces, rounded controls and restrained motion.

The raised-button treatment was informed by a supplied screenshot accompanying [this Figma community reference](https://www.figma.com/community/file/1112677564637285301/neumorphism-ui-buttons). Automated access to the Figma file was unavailable; its contents were not reviewed.
