---
name: planning
description: 'Turn a request into a small, verifiable implementation plan.'
---

Read the current project board and relevant repository context before planning. Identify the desired outcome, existing capabilities and concrete gaps.
Propose the smallest dependency-ordered steps, with acceptance criteria and verification for each meaningful change. Separate necessary work from optional improvements and identify unresolved decisions.
Do not start implementation merely because planning was requested. Do not create or modify board tasks without user intent. Continue in the same conversation when the user authorizes implementation.
