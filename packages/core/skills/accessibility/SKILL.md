---
name: accessibility
description: 'Review and improve keyboard, screen-reader and visual accessibility.'
---

Inspect the actual interface and semantics. Check accessible names, label associations, headings, keyboard order, focus visibility and restoration, dialog focus handling, disabled states and announced errors.
Check contrast, zoom, reduced motion and narrow layouts using existing design tokens. Prefer native elements over custom ARIA behavior. Do not claim compliance based only on automated checks.
When asked to implement, fix the specific barriers with minimal changes and verify keyboard behavior. When asked to review, report concrete barriers and their effect without editing files.
