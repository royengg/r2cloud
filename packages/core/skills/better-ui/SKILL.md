---
name: better-ui
description: 'Polish interfaces using the project’s existing design system.'
---

Inspect the existing components, design tokens and nearby screens before proposing changes. Preserve established colors, typography and interaction patterns.
Group related controls, align edges, keep spacing deliberate, and make primary actions easy to identify. Handle loading, empty, error, disabled and long-content states. Use semantic controls, accessible names, visible focus and keyboard navigation.
For implementation requests, make the smallest coherent change. Check narrow and wide layouts and review a screenshot when a browser is available. Explain what was verified and any remaining limitations. For questions or reviews, provide advice without editing files.
